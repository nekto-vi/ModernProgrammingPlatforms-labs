## Запуск

Установите и запустите Docker Desktop, затем в этой папке выполните:

```sh
docker compose up --build
```

При первом запуске PostgreSQL создаёт таблицы. Отдельный сервис `seed` загружает
страны, города и места из Overpass; сбор может занять несколько минут. Сервисы
приложения запускаются независимо от загрузки данных, поэтому недоступность
внешнего API не блокирует сайт. Фактическое количество записей выводится в
логах `seed`; при ошибке проверьте доступность API и повторите `docker compose run --rm seed`.

После запуска:

- Приложение: http://localhost:5173
- GraphQL Gateway: http://localhost:4000
- GraphQL Playground (через Apollo landing page): http://localhost:4000
- Jaeger: http://localhost:16686
- PostgreSQL с хоста: `localhost:5433` (внутри Compose: `postgres:5432`)

Остановить сервисы можно командой `docker compose down`. Данные PostgreSQL и
Redis сохраняются в Compose volumes.

Фронтенд отправляет GraphQL-запросы и мутации через Gateway. Apollo Gateway не
проксирует GraphQL-подписки, поэтому обновления новых отзывов подключаются по
GraphQL WebSocket непосредственно к `ws://localhost:4003/graphql`.

## Полезные команды

```sh
docker compose logs -f seed
docker compose logs -f gateway catalog-subgraph external-subgraph reviews-subgraph
docker compose run --rm seed
docker compose down
```

## Поиск мест

Введите полное название заведения или его часть и нажмите «Найти». Поиск
регистронезависимый и проверяет совпадение именно в названии места. Страну,
город и категорию можно дополнительно выбрать фильтрами; сортировка и страницы
результатов работают независимо от строки поиска.

По умолчанию выбраны Беларусь и категория «Ресторан». Скрипт загрузки сначала
добавляет в базу 10 явно помеченных учебных примеров из Минска, Бреста и Гродно,
поэтому интерфейс остаётся демонстрабельным даже при недоступности Overpass.
Это демонстрационные записи, не реальные заведения.

Список мест загружается скриптом `database/seed.js` из OpenStreetMap через
Overpass API и сохраняется в PostgreSQL. Карточка может дополнительно показать
краткое описание из Wikipedia и текущую погоду для города из Open-Meteo. Эти
сведения загружаются отдельно от поиска и могут отсутствовать, если внешний
источник не нашёл информацию или временно недоступен. Если список пуст, проверьте
`docker compose logs seed`; после восстановления доступа к Overpass повторите
загрузку командой `docker compose run --rm seed`. Чтобы добавить только страны,
города и учебные примеры без ожидания Overpass, выполните
`docker compose run --rm -e SEED_OVERPASS=false seed`.
