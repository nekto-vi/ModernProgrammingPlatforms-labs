# Клеточный бой

Минимальная многопользовательская игра по обязательным требованиям лабораторной работы №4:

- браузерный JavaScript без фронтенд-фреймворков;
- два игрока в общей комнате с синхронизацией ходов через WebSocket;
- ручная расстановка флота на поле 10 × 10: 4 однопалубных, 3 двухпалубных, 2 трёхпалубных и 1 четырёхпалубный корабль;
- начало партии только после готовности обоих игроков;
- сохранение комнат и состояния партии в `data/rooms.json` между перезапусками сервера.

## Запуск

Требуется Node.js 18 или новее.

```sh
npm install
npm start
```

Откройте `http://localhost:3000`, введите имя и создайте комнату. Второй игрок открывает тот же адрес, вводит своё имя и присоединяется по коду комнаты. Во время подготовки оба игрока видят свои поля и закрытое поле соперника; справа расположены размеры кораблей и оставшееся количество. Выберите корабль и протяните линию по нужным клеткам. Корректное положение подсвечивается синим, недопустимое — красным. Корабли не могут пересекаться или соприкасаться, в том числе по диагонали. Кнопка поворачивает корабль для размещения щелчком. Партия начинается, когда оба нажмут «Готово». Попадание оставляет ход игроку; промах передаёт ход сопернику. Когда корабль потоплен, клетки вокруг него автоматически отмечаются красным и больше не требуют выстрелов.

`PORT` задаёт порт сервера, `DATA_DIR` — каталог для файла сохранений.
